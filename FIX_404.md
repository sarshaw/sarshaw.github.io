# Fix 404 Error - Step by Step

## The Problem
GitHub Pages is **NOT ENABLED** on your repository. This is why you're getting a 404.

## Solution: Enable GitHub Pages

### Step 1: Go to Repository Settings
1. Visit: https://github.com/sarshaw/sarshaw.github.io
2. Click the **Settings** tab (top menu, far right)
3. Scroll down in the left sidebar and click **Pages**

### Step 2: Configure GitHub Pages
In the Pages settings:
1. Under **Source**, select: **Deploy from a branch**
2. Under **Branch**:
   - Select: **main** (or **master** if that's your default branch)
   - Select folder: **/ (root)**
3. Click **Save**

### Step 3: Wait for Build
- GitHub will automatically start building your site
- You'll see a yellow dot → green checkmark when done (1-2 minutes)
- Check the **Actions** tab to see build progress

### Step 4: Verify
- After 2-5 minutes, visit: https://sarshaw.github.io
- Your site should be live!

## If It Still Doesn't Work

### Check Build Status
1. Go to: https://github.com/sarshaw/sarshaw.github.io/actions
2. Look for "pages build and deployment" workflow
3. If there's a red X, click it to see errors
4. Common errors:
   - Syntax errors in `_config.yml`
   - Missing required files
   - Plugin issues

### Force Rebuild
If needed, trigger a rebuild:
```bash
git commit --allow-empty -m "Trigger rebuild"
git push
```

### Verify Repository is Public
- GitHub Pages requires public repositories (for free accounts)
- Go to Settings > General > scroll to bottom
- Make sure "Change repository visibility" shows it's **Public**
